## 1. wechat-agent-sdk 0.2.1（venv：wechat-claw/.venv/）

- `transport.py` — WeChatTransport（消息收发/媒体/轮询）；`api/client.py` — SessionExpiredError（会话过期，抛前清 token）
- `acp/adapter.py` — AcpAgent（SDK 的 on_start 引用不存在的 PermissionOutcome → bridge/session.py 的 ConfirmAcpAgent 重写绕过）
- `media/cdn.py + crypto.py` — CDN 加解密
- **本地补丁四处**（pip 升级会覆盖 → 重打脚本 `patches/apply_patches.py`，幂等 + py_compile + 关键行断言校验）：
  - ① cdn.py：`aes_key_b64 = base64.b64encode(key.hex().encode()).decode()`（格式 B，微信端可解密）
  - ② transport.py：`_build_media_item(..., file_size: int = 0)` + file 分支加 `len` 字段
  - ③ cdn.py：download URL 用 `quote(encrypt_query_param, safe='')` + `/download` 路径
  - ④ cdn.py：`from urllib.parse import quote`（③ 的符号依赖，保证补丁后文件可运行）
- **私有 API 使用点**（SDK 升级兼容检查项）：`main.py` 用 `transport._storage.load_token("default")` / `transport._client.token`（登录 token 恢复）、`session.py` 用 `agent._sessions.pop(...)`（会话归档）——以下划线开头成员升级可能改名/删除，升级前先验证存在性

## 2. bridge/（四大块，基础设施）

| 文件 | 职责 |
|---|---|
| `main.py` | 入口编排：transport/agent/会话组装、消息循环（含入站路由 _route_inbound：模块 inbound 订阅优先于 agent）、push_worker/retry_worker；S1 捕获（SessionExpiredError → SystemExit(1)） |
| `push_server.py` | /push HTTP 入口：token 验算（index 哈希 + push_token）→ 校验 body（type ∈ 六类、≤100MB）→ 入队（有界 100，满 503）；401 记日志 |
| `scheduler.py` | 通用调度引擎：build_index() → 四态规则判定器（cron 增强/列表区间步进、every、window 严格版+窗格内补发、once 一次性）→ spawn 模块（300s 超时，拒混入 --dry-run；**注入 PYTHONPATH=项目根+modules/**，worker 可 import bridge）→ rc 感知（rc≥2 引擎级异常不补发）→ retry 补发；调度前**完整性快检**（基准不符拒绝执行）+ 每日全量校验 |
| `opencode_jobs.py` | **wechat-claw 自建 job 调度（跨平台）**，与 opencode 官方 scheduler 插件互不依赖：cron 统一解析（_parse_cron：数字/*/步长/列表/区间；dom+dow 双非 * 三平台一致拒绝）→ 三平台精确定时器——Linux systemd OnCalendar / macOS launchd StartCalendarInterval / Windows schtasks（列表 cron 拆多任务）；`supervisor` 子命令 = **纯 Python 执行器**（平台定时到点触发：防重锁 → 执行 opencode（job.env 注入 XDG）→ lastRun 状态写回 → jsonl 日志）；统一入口 `<program> -m bridge.opencode_jobs supervisor <job.json>`（源码=venv python / 打包=exe 自身）；scopeId=wechat-claw、slug=<模块名>-<任务名> |
| `jobs.py` | job 模板合成与登记联动：_compose_prompt（通用占位符：{date}/{module_data}/{output_path}/{settings:键}/{custom_prompts}）→ 模块保存设置时自动 render + install_job 登记；模板 = 明文 `prompts/base.prompt.md`（enc 仅兼容旧，跨机解密失败按缺失） |
| `module_source.py` | 模块源管理：源 CRUD + 拉取（GitHub 浅克隆/本地目录）→ manifest 验签（Ed25519，仅 builtin 强制）→ 安装/更新（校验清单/结构/sha256，.bak 备份回滚，跳过 token）→ 每日指纹驱动更新；**运行时完整性校验**（verify_module_integrity/verify_all_modules：installed.json 基准 sha256+files 重算比对，防部署机本地篡改） |
| `paths.py` | 文件发送三级规则（reject 硬拒/gate 微信确认/default 直发）与路径规范化（resolve 防 ../ 与符号链接） |
| `permissions.py` | 模块越界豁免片段（.config/module-permissions.json，供合并进 opencode.jsonc；模块 module.json 自声明 + register 合并） |
| `session.py` | SessionManager（5h 窗口，归档移除会话键）/ PermissionGate（微信确认）/ ConfirmAcpAgent（SDK bug 修复） |
| `state.py` | 纯 IO：token 生成（chmod 600）/ retry 队列 / 调度状态（原子写 tmp+rename）/ 会话目标读取 |
| `config.py` | **基础设施配置层**：读 `<项目根>/.config/config.yaml`（点号路径 `get("push.port")`）；`DEFAULTS_RUNTIME`（运行参数，文件不可覆盖）+ `DEFAULTS_USER`（用户段可配）；`resolve_path()` 相对项目根解析路径；`resolve_opencode()`（acp.command→PATH→~/.opencode/bin 同源寻址）；bridge 与 modules/common 共用 |

## 3. modules/（平台基础设施 + 业务模块）

> 平台只含基础设施：common/（数据公共库）+ register.py + registry_index.py。
> **业务模块在独立模块源仓库**（wechat-claw_modules_official），从源安装到 `modules/<name>/`（见模块源 README），
> 本平台文档不列具体业务模块实例（示例见 docs/04 的 module.json 格式与调度四态）。

- 模块自描述（module.json）为**纯声明**：name/purpose/spec/settings_schema/schedule（静态 + schedule_from_settings 联动产物）/inbound/permissions/job_template；部署状态（enabled/retry/auto_update）在数据区 settings.json

- `register.py`：**模块管理器（唯一入口）**——注册（token 0600，仅新模块发卡）/ 更新（已存在模块走 update_module，**token 不变**，G1）/ 补卡（`--reissue-token`，仅缺失时，H8）/ 启停（`--enable/--disable`，enabled 默认 false）/ 列表（`--list`，含禁用）/ 卸载（`--uninstall`，同步清调度状态，G5）；函数库形态供 web 调用
- `registry_index.py`：build_index() 实时扫描 module.json + token 文件 → 汇总 index（**仅含 enabled=true 且 token 存在**的模块；token 缺失不进 index 并告警，H8；scheduler/push_server 数据源）

## 5. /push 协议

```
POST http://127.0.0.1:9898/push
Headers: Authorization: Bearer <token>（或 X-Token）
Body: {"type": <type>, "text": "...", "path": "..."}

type 分类：
  direct（原文直发）：briefing / notification / text / file（file 发文件原件，path 必带）
  agent（加工后发）：reminder / alert

响应：200 入队 / 400 非法 body / 401 鉴权失败 / 404 路径错 / 413 超 100MB / 503 队列满
```
